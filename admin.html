第一步：GitHub 访问令牌 未设置

令牌只保存在你这台浏览器的 localStorage 里，不会写进仓库代码。建议在 GitHub → Settings → Developer settings → Fine-grained tokens 新建，仅授权本仓库的 Contents: Read and write；有效期可设 90 天，到期重新生成即可。

第二步：上传项目文件夹

选择学生项目的整个文件夹，文件夹名就是他的登录账号，密码在这里设置。 上传后会自动更新 users.js 的项目列表和账号，约 1 分钟后门户生效。

注意

1. 令牌等于你账号的写权限，别在公共电脑上保存，用完可到 GitHub 撤销。
2. 密码以 SHA-256 哈希写入 users.js，源码里看不到明文；但站点仍是公开的，项目文件本身可通过直链访问。
3. 同名文件夹重复上传会覆盖其中的文件，但不会删除旧的多余文件。
